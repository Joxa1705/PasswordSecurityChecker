# 🔐 Password Security Checker

A desktop password security analysis tool built with Python and Tkinter.

Password Security Checker is a defensive cybersecurity application designed to analyze password security using multiple security signals. The application provides password analysis, weak-pattern detection, breach checking, security policies, educational guidance, analytics, audit logging, automated testing, error handling, and Windows executable packaging.

The project was developed as a cybersecurity portfolio project to demonstrate practical Python programming, GUI development, security analysis, testing, logging, error handling, and application packaging.

# 🚀 Features

## 🔎 Password Analysis

The application analyzes passwords using multiple security signals:

- Password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters
- Entropy
- Common-password detection
- Weak-pattern detection
- Username similarity
- Breach exposure
- Security score
- Risk level
- Security health

The application combines these signals to provide a security report for the tested password.

---

## 🧩 Pattern Analysis

The pattern-analysis system detects several types of weak password patterns.

### Keyboard Patterns

Examples include:

- `qwerty`
- `asdf`
- `zxcv`
- `qaz`
- `wsx`
- `qazwsx`
- Other common keyboard sequences

- Sequential letters
